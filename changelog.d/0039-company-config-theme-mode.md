[Bug Fixes]
- Colours delivered through `company-config.json` no longer revert when a user logs in or toggles light/dark. `applyThemeMode()` rebuilt the theme from the built-in light or dark base and carried over only branding and login, so an operator's palette was discarded on the first mode change. Brand and status colours now survive both modes; navigation and layout surfaces continue to follow the mode, since the config expresses a single light palette with no dark counterpart. The default install was unaffected — the shipped config repeats the built-in theme's values exactly, so the overwrite replaced each colour with an identical one and only a customised palette ever showed the fault.
